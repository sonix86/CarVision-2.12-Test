# CarVision 1.9 — переносимый Windows-прототип

Владелец: София Рахманкулова. Программа автоматически находит машины и предлагает марку, конкретную модель и цвет. Работает локально, без API, ключей, оплаты и сети при анализе.

## Запуск и перенос
Распакуйте TashkentCarVision-v1.9-Portable.zip целиком. Запустите CarVision/CarVision.exe или Start CarVision.cmd. Для другого Windows x64-компьютера переносите ВСЮ папку CarVision, включая models и _internal. Установка Python для анализа не требуется. Проверка отдельной копии на этом ПК не доказывает совместимость со всеми другими устройствами.

Откройте фото → «Анализировать фото». Марку выбирать не нужно. «Выбрать зону мышью» → обведите одну машину → распознайте в зоне. Полный контекст сохраняется, соседние видимые маски исключаются из её цвета. Двойной щелчок открывает крупный просмотр. Справа показаны до3 гипотез и весь список изученных моделей. Знак вопроса означает предположение, а не установленную модель.

В «Подробных настройках» есть «Объединить части одной машины»: отметьте её ошибочно разделённые контуры. Объединяются только уже видимые пиксели, ответ рассчитывается заново; действие можно отменить. Автоматическая ассоциация использует общее предложение детектора, простая близость машин не является основанием объединения. Ошибки ассоциации всё ещё возможны. Разные цвета контуров различают экземпляры; цвет кузова показан отдельно.

TXT/«Ответ для задания» содержат пары brand colour. Подробный TXT, JSON и JPG содержат модели/варианты, уверенности, контуры и раздельную легенду. Русский текст JPG поддерживает кириллицу. Числа сети относительны и не гарантируют ответ.

## Фотографии и самостоятельное обучение
Отдельный архив CarVision-Real-Chinese-EV-Photos-v1.9.zip содержит244 найденные реальные фотографии, авторов, лицензии и train/validation/test принадлежность. Ни одна фотография не сгенерирована.194 снимка прошли фильтрацию; из них137 train,30 validation,27 test.146 новых групп съёмки. Уличные сцены без разметки всех автомобилей не превращены в подписанные обучающие машины. Дубликаты, интерьер, неверно описанный главный объект и слишком малые/неоднозначные вырезки исключены; причины сохранены.

В «Примеры фото» доступны images(6 городских диагностических кадров), Chinese_EV_Test(8 детерминированно выбранных новых test-фото) и Street_scenes(8 неразмеченных сцен). Новые test-примеры не использовались для обучения/выбора параметров, но их просмотр не заменяет проверку на своих новых фото. Лицензии каждой фотографии — samples/EV_PHOTO_SOURCES.json и отдельный фотоархив. Некоторые фотографические семейства присутствуют только в наборе для дальнейшего расширения, а не в активном классификаторе.

Для задания нужен собственный набор Ташкента. «Учебная разметка» сохраняет ваши марки, цвета и группы. Во вкладке «Обучение» расписаны4 шага: разметить → проверить → обучить → оценить. Эта кнопка обновляет отдельный классификатор марок/цветов и резервный детектор рамок; контурный COCO-сегментатор и список названий моделей она не переобучает. Рецепты обучения моделей кузова находятся в source/tools. Старые веса сохраняются. Импорт обычного тестового фото ничего сам по себе не обучает.

## Измерения и границы
Выбран кандидат hybrid; активных семейств моделей: 32. Общие ImageNet/COCO-веса разрешены, готовые автомобильные классификаторы марок/моделей/цветов не используются. Выполнены2 ограниченных нейросетевых раунда,16+16 эпох, плюс обучение/подбор собственного сравнения деталей на train/validation. Кандидаты и параметры выбраны только по validation. Цвет не запрещает возможную модель.

Для честного сравнения обнаружены7 старых авторских сессий, попавших в разные split у разных марок.3 validation и5 test изображений исключены из новых оценок. Исходные старые split не перетасованы, прежние test не перемещены в train. Старый чистый train/validation/test:642/131/389. С новыми данными:779/161/416. Сессия author/date — приближение; настоящие идентификаторы всех машин публичных источников отсутствуют.

| Видимые данные | v1.8, test 389: top1 / top3 | v1.9, те же test 389: top1 / top3 |
|---|---|---|
| Весь автомобиль | 78.1% / 93.3% | 79.2% / 94.1% |
| Верхние 55% вырезки | 47.0% / 71.5% | 48.1% / 73.8% |
| Верхние 35% вырезки | 19.8% / 49.6% | 19.5% / 47.6% |

На 27 новых test-снимках: top1 25.9%, top3 74.1%. На отдельную модель приходится всего3–5тестовых фото, поэтому это ограниченная оценка.

Top1 — первый вариант совпал с подписью; top3 — верный вариант есть среди трёх. Верхние вырезки имитируют отсутствие деталей, не являются полноценным тестом реальной городской окклюзии. Исторические опубликованные оценки1.8на394изображениях не сравниваются напрямую с очищенными389. Все результаты, выбор и размеры выборок: models/release_v19_comparison.json. Ошибки по редким Cobalt/Damas/Nexia и незнакомым семействам остаются; у этих классов недостаточно независимых примеров, для некоторых нет validation. Точного определения любого автомобиля по любой крыше/значку/цвету программа не гарантирует. Отдельный детектор значков не заявляется. Видимая маска не восстанавливает скрытый кузов.

Новые марки, которых нет в прежней18-классовой голове марок, могут быть выведены из уверенного собственного классификатора модели. Семейства Yuan Plus/H6 и другие могут включать поколения и варианты; распознавание имени не определяет двигатель, комплектацию либо чистую электрическую тягу. При слабых данных остаются гипотезы/unknown.

Изученные модели: BYD Song Plus; Chery Tiggo 7; Chevrolet Captiva; Chevrolet Cobalt; Chevrolet Damas; Chevrolet Lacetti; Chevrolet Malibu; Chevrolet Nexia; Chevrolet Onix; Chevrolet Spark; Chevrolet Tracker; Daewoo Matiz; Daewoo Nexia; Haval Jolion; Kia K5; Lada 2101; BMW 3 Series Sedan 2012; Honda Accord Sedan 2012; Hyundai Accent 2012; Hyundai Santa Fe 2012; Hyundai Sonata 2012; Hyundai Tucson 2012; Toyota Camry 2012; Toyota Corolla 2012; BYD Qin Plus; BYD Seagull; BYD Seal; BYD Yuan Plus; Chery Tiggo 8; Geely Galaxy E5; Haval H6; Zeekr 001.

## Исходники и задание
source содержит редактируемый проект и рецепты. Для разработки создайте Python 3.12 venv, установите requirements-lock.txt, собирайте build.ps1. Для повторного исследования нужны исходные открытые данные/кэши по provenance, они целиком не вложены в программу; новые244 фото есть в отдельном архиве. Переносимый анализ использует включённые веса и сеть не требует.

Собственных учебных фото студента пока0; публичные снимки это требование PDF не заменяют. GitHub-ссылка не предоставлена, публикации не выполнялись. Очный телефонный цикл/20новых снимков, запуск на другом физическом ПК, подтверждение уникальности ML-семейства преподавателем и финальные сведения о вкладе ещё не выполнены. Шестистраничный PDF в docs сохраняет исторический протокол1.5, не является обновлённым отчётом1.9или свидетельством полной сдачи. Никакие данные, история работы и результаты не выдуманы.


## Проверка целых новых фотографий после выбора модели
На 27 независимых новых фотографиях программа нашла хотя бы одну машину в каждом кадре. Для самой крупной видимой машины первая гипотеза совпала с исходной подписью в 7/27 случаях (25.9%), правильная модель присутствовала среди трёх в 21/27 (77.8%). Единственный ответ, показанный как подтверждённая модель, был ошибочным. Это малая выборка и явное ограничение качества: расширенная китайская таксономия пока экспериментальная. Полной точности на сложных сценах не достигнуто. Отдельной разметки всех контуров этих кадров нет, поэтому 27/27 не объявляется precision/recall детектора. Цвета на новом наборе не имеют проверенных целевых подписей, их новая точность не заявляется.
Статистика сохранена в models/ev_end_to_end.json. После этого теста веса, пороги и ранжирование не менялись. Снижение top3 на самых узких 35% старых тестовых вырезок отражено в таблице выше; кратное улучшение не обещается.
