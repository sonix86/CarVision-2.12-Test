# CarVision2.0 — Chevrolet и вырезки кузова

Владелец: София Рахманкулова. Анализ локальный: без API, ключей и оплаты. Распакуйте TashkentCarVision-v2.0-Portable.zip целиком и запустите CarVision/CarVision.exe. Переносится вся папка с models и _internal; Python для анализа не нужен. Проверка отдельной копии на этом ПК не гарантирует совместимость со всеми другими Windows-устройствами.

Изменение2.0: дополнительный классификатор сохраняет пропорции кузова при подготовке изображения, вместо растягивания каждой машины в квадрат. Он обучен нами на779 тренировочных фото с уменьшенными вырезками и фрагментами кузова. Общий ImageNet ResNet18 служит только начальной системой признаков; автомобильный классификатор не скачивался.32семейства сохранены, расширение списка моделей не было целью итерации. Цвет не ограничивает возможную модель. Детектор видимых экземпляров в этой версии не переобучен.

Выбор выполнен только по 161 validation-фото. Первый цикл остановлен после 9 эпох для исправления совпадения вырезок и масок; затем выполнен исправленный цикл 12 эпох, выбран проход 6. Test из 416 фото не использовался для подбора параметров. Модель обучается в разработке; ваши обращения к чату сами по себе не обучают программу.

Это проверка классификации вырезок, а не точность всех машин в любой городской сцене. Уменьшенные/верхние виды — преобразования тех же test-фото, не дополнительные независимые наблюдения. Cobalt имеет всего2старых test-фото, Chevrolet Nexia —1, Damas —0; validation для этих трёх семейств отсутствует. По ним нельзя объявлять достигнутую надёжность. Крыша, блики на стекле, перекрытия и не представленные поколения всё ещё могут дать неправильный первый вариант. Знак вопроса обозначает гипотезу. Новые12публичных Chevrolet-фото — диагностические материалы, не обучающие данные и не репрезентативный замер точности.

Откройте фото → «Анализировать фото». Марка выбирается автоматически. «Выбрать зону мышью» позволяет обвести одну машину. В подробных настройках можно объединить ошибочно разделённые части и пересчитать ответ, с отменой действия. Правый блок показывает до 3 вариантов и полный список 32 семейств. Свидетельства разных моделей одной марки суммируются: уверенность в Chevrolet не означает уверенности именно в Cobalt. Порог марки калибруется отдельно на validation. Старый классификатор марки корректируется новым только при высокой уверенности; известные марки вне словаря моделей сохраняются. Никаких ответов по имени файла или правил «все машины здесь Chevrolet» нет.

TXT/«Ответ для задания» содержат brand colour; подробные TXT/JSON/JPG включают модели, варианты, цвет и видимые контуры. Скрытые детали не восстанавливаются. Кнопка обучения объясняет самостоятельную разметку и обучение марок/цветов; она не переобучает автоматически32модельных семейства или сегментатор. Для этого нужны отдельные исходные данные и разработческие scripts.

Отдельные JPEG находятся в samples/Chevrolet_Diagnostics; авторы, лицензии, исходные ссылки — samples/CHEVROLET_PHOTO_SOURCES.json. Архив CarVision-Chevrolet-Real-Photos-v2.0.zip содержит те же12фото. Предыдущие244реальные китайские/EV-фото и их лицензии сохранены из1.9.

Получены10 ваших фото Ташкента, вручную размечены9 машин (8 с моделью). Все кадры одной поездки закреплены только за train. Дополнительный12-эпоховый эксперимент на этих данных отклонён по validation; выпускаемые нейронные веса пока обучены на публичных данных. Требования собственного обучающего набора как основы проекта, GitHub-ссылки, нового итогового отчёта и живой проверки20 снимков остаются открытыми. Уникальность среди команд требует сверки с преподавателем. Исторический PDF1.5 сохранён с правильной фамилией, но не является новым финальным отчётом2.0. История1.9 и её отдельные результаты сохранены в docs/history-v19.
