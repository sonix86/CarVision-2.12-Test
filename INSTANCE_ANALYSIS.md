# CarVision1.8: видимые машины и сравнение деталей

Владелец: София Рахманкулова. Нормальный режим ищет общие COCO-маски машин/грузовиков; собственные модели определяют марку, модель и цвет. Маски описывают только видимые пиксели. Пиксель принадлежит одному объекту; цвет соседнего кузова исключается. Скрытые детали не восстанавливаются.

Ручная зона указывает нужную машину, поиск сохраняет контекст полного кадра и обрезает выбранную маску зоной. Если контур не найден, пробуется крупный участок и затем приблизительный GrabCut с предупреждением. Приблизительная маска не подтверждает наличие автомобиля. Последние маски кэшируются по пикселям и настройкам, не по имени файла.

## Новая модель

Собственная MobileNetV3Small с avg/max pooling,256hidden,24 выходами; стартовала от собственной версии1.7. Train642, validation134, test394;24эпохи AdamW, featureLR0.000045/head0.0003,wd0.015,cosine24,CE smoothing0.05,balanced sampling. Смешиваются целые, верхние35%/55%, боковые65% и центральные детали,60% изолированного фона, отражение, цветовые изменения и25% grayscale. Конкретного выделенного логотипного классификатора нет.

Выбран22-й epoch по validation: среднее top1+0.5top3 для whole/upper55/upper35 с ограничением старых полных вырезок. Далее подобраны параметры сравнения только по validation и проверены старые whole top1/top3 и upper55/upper35 top3 с допуском2пункта относительно1.7. Все результаты test вычислены после выбора; городской набор не определяет параметры.

Банк6420 представлений train-only использует256 признаков собственной сети. Косинусное сходство штрафуется за разницу соотношения сторон. Для класса усредняются3 ближайших представления (они могут быть из одной фотографии). Параметры: температура0.03,штраф0.15,вес банка0.25 и сети0.75; исходный/изолированный вид0.75/0.25; итоговая температура1.0,порог модели0.7. SHA256 сети связан с банком: старый банк с другой сетью не применяется.

24 изученных класса,8 новых с явным годом2012. Классификатор замкнут на этот список: чужая модель может быть похожа на известную. При конфликте марки и сильного модельного сравнения название не подтверждается. Фрагменты с отношением ширины к высоте>3.2, короткой стороной<64px рабочего кадра,маской<1200px или обрезкой границей кадра не подтверждают название. Это эвристические предупреждения, не оценка скрытой площади.
