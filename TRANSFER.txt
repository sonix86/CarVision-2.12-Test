CARVISION 2.1 / София Рахманкулова
Распакуйте TashkentCarVision-v2.1-Portable.zip целиком.
Запустите CarVision/CarVision.exe. Переносите всю папку CarVision,
включая _internal, models, data и samples. Один EXE отдельно не работает.
Windows10/11 x64, папка должна разрешать запись. Python для анализа не нужен.
Открыть фото -> Анализировать фото.
Выбрать зону мышью -> обвести машину -> Анализировать фото.
«Ответ для задания» копирует английские brand colour.
32 модельных семейства - дополнительная функция, не гарантия точности.
Эмблемы пока не подтверждены отдельной валидацией, их влияние отключено.
Все вычисления локальные, без API/ключей/платежей.
Проверена отдельная копия на этом компьютере без Python в PATH.
Запуск на другом физическом компьютере пока не проверен.
README.md и REQUIREMENTS_AUDIT.md перечисляют незавершённые требования.
