# Инженерные проверки CarVision 1.3 — 20 октября 2026

Владелец: София Рахматулаева. Windows x64; Python 3.12.14, torch 2.6.0+cpu, torchvision 0.21.0. Общие веса ImageNet/COCO разрешены владельцем; классификатор марок обучен в этом проекте.

- **30 регрессионных тестов прошли**: автоматический вывод марки/цвета без ручного выбора, поиск машин внутри области, прямой анализ одной обведённой машины без детектора, восстановление глобальных координат, сброс/масштабирование области, отбрасывание фрагментов разных проходов с сохранением вложенных объектов одного прохода, размещение номеров без пересечений, отдельная экспортная легенда, конечные признаки цвета, split дубликатов, уникальные экспорты, формула оценки и ограничения отчёта.
- GUI: четыре раздела, загрузка своего фото/примеров, корректные диалоги и пути, копирование/экспорт, сохранение и отмена метки, группы, масштабирование координат, размещение кнопок при минимальном окне, команды audit/evaluate/train и остановка дочернего процесса проверены программно во временной папке.
- Настоящие поставляемые модели проверены на **6 отдельных городских JPG**, с программно заблокированным socket.connect. Файлы weights загружаются локально; скрытого обращения к интернету нет.
- Одинаковое изображение после переименования даёт те же результаты: имя/путь не служат таблицей готовых ответов.
- На настоящих весах отдельно проверены оба режима области. Прямой анализ возвращает ровно одну рамку исходных координат и 0 проходов детектора. Для поиска в области все восстановленные рамки остаются внутри неё. Режим одной машины также проверен в перенесённом EXE.
- Время режима fast на этих шести изображениях на данном CPU: от **6.72 до 8.39 с**, без передачи с телефона. Это измерение скорости, а не подтверждённая точность всех машин на этих улицах.
- EXE перенесён в отдельную папку с пробелами в пути; PYTHONHOME/PYTHONPATH очищены, PATH содержит только Windows. Проверены реальные weights, inference и создание TXT/JSON/JPG. Исходный Python или папка разработки не нужны.
- Запуск собранного кода сравнивается с исходным по результатам на том же снимке. Дополнительно сигнатуры bytecode модулей core/gui/training/detector_training/reporting внутри PyInstaller проверены на соответствие исходникам.
- Реальное обучение/точность/матрица ошибок и ограничения тестовой выборки описаны отдельно в PROTOTYPE_VALIDATION.md и models/evaluation/public_test.json. Синтетические демонстрационные веса не включены в релиз.

Окно новой версии дополнительно просмотрено на снимке интерфейса: компактные номера, список результатов, выбор области и кнопки помещаются. Программный layout test также проверяет минимальный размер окна.

Чего эти проверки не подтверждают: запуск на другом физическом компьютере, отсутствие любых ошибок на любых фото, 20 новых экзаменационных сцен, человеческую независимую точность цвета и полный цикл телефон → передача → ответ за 120 секунд. Собственных фото Ташкента пока нет.

Исходный PDF требований сверён в REQUIREMENTS_AUDIT.md. Итоговая учебная сдача требует собственного набора, GitHub, уникальности среди команд, отчёта и личного live test.
