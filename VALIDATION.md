# Проверки CarVision 1.1 — 20 октября 2026

Владелец: София Рахматулаева. Windows 10 x64, Python 3.12.14, PyTorch 2.6.0+cpu, torchvision 0.21.0. Требование владельца: никаких готовых весов; обе сети обучаются с нуля.

## Проверено

Повторная сверка PDF: REQUIREMENTS_AUDIT.md. Добавлены проверка автоматического вывода brand/colour без ручного ввода, эквивалентов Mercedes/VW/Lixiang в оценщике, обязательного обоснования архитектуры и отказа публиковать итоговый отчёт длиннее 6 страниц. Основной сценарий не изменяет готовность данных: реальных весов всё ещё нет.

- `pip check`: конфликтов зависимостей нет. `compileall`: исходники компилируются.
- **18 регрессионных тестов**: формула оценки задания и допустимые названия-эквиваленты, автоматическая передача вывода brand/colour без ручной марки, восемь HSV-цветов на искусственных полях, групповой split и дубликаты, неверные рамки, восстановление координат фрагментов, отбрасывание обрезанных рамок, объединение дубликатов, экспорт без перезаписи, отказ без своего детектора, требования к отчёту; GUI-проверки ниже.
- GUI: четыре раздела переключаются; кнопки загрузки своего фото и примеров вызывают нужные диалоги; PDF/папка открывают нужный путь; ответ копируется; экспорт создаёт файлы. Сохранение/отмена меток и сброс группы нового фото проверены в изолированной временной папке. Масштабирование разметки при изменении окна сохраняет исходные координаты. Кнопки результатов помещаются при минимальном размере 1120×760. Команды audit/evaluate/train передают правильные пути; остановка вызывает завершение дочернего процесса.
- Полный синтетический цикл: обучение классификатора и двухклассового SSDLite-детектора → сохранение собственных checkpoint → evaluation/confusion matrix → загрузка и inference. Оба этапа обучаются без готовых весов. Во время исходного цикла socket.connect заблокирован: скрытого скачивания весов нет.
- Тот же короткий цикл обучения обеих сетей выполнен через собранный EXE. Синтетические веса хранятся только в outputs; в поставку не включены.
- Загрузка синтетических team-trained checkpoint и inference выполнены с заблокированным socket.connect; проверены границы рамок и detail mode. Это проверка механики, **не точности на реальных машинах**.
- EXE перенесён в `outputs/Portable v1.1` (путь с пробелом); inference выполнен с пустыми PYTHONHOME/PYTHONPATH и PATH, содержащим только Windows. Установленный Python не используется исполняемым приложением.
- Код GUI, core и detector_training внутри PyInstaller PYZ сравнен с текущими исходниками по рекурсивной сигнатуре Python bytecode: совпадает.
- PDF примеров: **8 страниц**; 6 реальных снимков Ташкента, инструкция, лист проверки. Каждая страница отрисована и просмотрена; фото, подписи, авторы и лицензии читаются. Оригинальные JPG и metadata находятся в samples. Изображения в PDF пропорционально уменьшены. Файл не является экзаменационным отчётом.
- Генератор итогового отчёта после изменения архитектуры проверен на отдельном синтетическом fixture: 6 страниц. Эти примерные метрики и PDF не включаются в поставку как результаты проекта.

## Ограничения — не выдаются за выполненные этапы

- **Реальных размеченных фотографий владельца нет. Рабочие detector.pt/classifier.pt ещё не обучены.** Точность по Ташкенту не измерена. Код обработки фрагментов исправлен, но качество на боковых ракурсах/дальних машинах нельзя подтвердить без обученных сетей и независимых фото.
- Нет проведённого испытания на 20 новых телефонных фотографиях и полного времени передачи/обработки в 120 секунд.
- Другой физический компьютер пока не проверялся: подтверждён перенос между папками этого компьютера.
- Захват окна инструментом Windows завершился `FrameArrived timed out`; визуальный скриншот GUI не подтверждён. Вместо этого проведены перечисленные программные проверки layout/кнопок, а не заявлена визуальная проверка всего окна.
- Уникальность архитектуры среди команд, реальный GitHub URL/доступ преподавателя, индивидуальные вклады, финальный tag и сдача остаются отдельными этапами. История коммитов отражает реальные действия Codex и не подделывает историю студентов.

В финальном архиве отсутствуют COCO/ImageNet-веса, синтетические модели и журналы с неподтверждённой точностью. Локальные файлы прежнего прототипа в outputs/cache не загружаются текущим кодом и не включаются в релиз.
