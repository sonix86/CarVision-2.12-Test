# Tashkent CarVision 1.8

Владелец и участник: **София Рахманкулова**. Переносимый Windows10/11 x64 прототип: видимые контуры машин, автоматические марки, модели-кандидаты и восемь цветов. Всё распознавание локально, без интернета, API и ключей.

Распакуйте **TashkentCarVision-v1.8-Portable.zip** целиком и запустите **CarVision/CarVision.exe**. Переносите всю папку вместе с models, _internal, samples и data; EXE отдельно недостаточно.

1. «Открыть фото» → «Анализировать фото» для всего кадра.
2. «Выбрать зону мышью» → обведите нужную машину → «Распознать в зоне».
3. Нажмите контур или строку: справа три варианта и цвет. «Все изученные варианты» показывает ранжирование24 классов.
4. «Крупнее» показывает выбранную видимую часть. «Вся фотография» снимает зону.
5. «Ответ для задания» копирует пары brand colour. «Копировать варианты» добавляет модели. Экспорт сохраняет TXT, details.txt, JSON и JPG.
6. «Подробные настройки» раскрывают поиск мелких машин и объяснение порогов. Для начала оставьте0.5.

## Что изменилось

Сохранены исходные группы536 региональных фото и добавлены634 уже имеющихся снимка с точными оригинальными модельными MAT-подписями Stanford Cars. Всего1170 фото:642train,134validation,394test.24эпохи обучения, выбран22-й проход только по validation. Сравнение видимых деталей использует6420 представлений только из train: целые машины, верхние и боковые фрагменты. Городские примеры не входят в обучение или выбор параметров.

Восемь новых классов обозначены годом2012: это конкретные представленные кузова, не знание всех поколений. Изученные варианты: BYD Song Plus; Chery Tiggo 7; Chevrolet Captiva; Chevrolet Cobalt; Chevrolet Damas; Chevrolet Lacetti; Chevrolet Malibu; Chevrolet Nexia; Chevrolet Onix; Chevrolet Spark; Chevrolet Tracker; Daewoo Matiz; Daewoo Nexia; Haval Jolion; Kia K5; Lada 2101; BMW 3 Series Sedan 2012; Honda Accord Sedan 2012; Hyundai Accent 2012; Hyundai Santa Fe 2012; Hyundai Sonata 2012; Hyundai Tucson 2012; Toyota Camry 2012; Toyota Corolla 2012.

Форма, детали и фактура сравниваются собственной нейросетью и учебными представлениями; отдельный обученный детектор значков не заявляется. Цвет не служит жёстким запретом модели: при обучении применяются вариации освещения/цвета и25% чёрно-белых вариантов.

## Измерения и ограничения

Сопоставимый тест прежних16 моделей,80 вырезок:

| Вид | Top-1 до → после | Правильная модель среди3 до → после |
|---|---:|---:|
| Целая вырезка |78.8% →77.5%|93.8% →91.3%|
| Верхние55% |42.5% →52.5%|65.0% →67.5%|
| Верхние35% |22.5% →23.8%|46.3% →56.3%|

Для восьми новых классов:314 официальных test-вырезок, top-1 целого кузова78.3%, top-3 93.9%. Это другой поднабор, его нельзя подменять сравнением со старыми80 фото. Общая тестовая выборка394, top-1 полного кузова78.2%, top-3 93.4%. Кандидат выбран по заранее заданным validation-ограничениям; тест не подбирает параметры. Часть показателей полного кузова снизилась, поэтому универсальный или кратный рост не заявляется. Верхние вырезки искусственные, не полноценный уличный тест.

Узкие, маленькие и обрезанные фрагменты показывают «Недостаточно деталей». Варианты остаются доступны; проценты относительны к изученным классам. Неизученная машина может получить похожий известный вариант. «?» - предположение; «≈» - неуверенный цвет. Ошибки цвета, марки, модели и границ сохраняются.

## Обучение и задание

Для обычного анализа переобучение не нужно. Вкладка обучения объясняет четыре шага и показывает объём своего набора. Её кнопка обучает марки/цвета и резервный детектор по вашей разметке, но не добавляет новые конкретные модели или COCO-маски. Рецепты расширения моделей находятся в source/tools.

Собственных учебных фото пока0, GitHub не предоставлен. Собственные фото Ташкента, согласование уникальности архитектуры, полный телефонный цикл,20 невиденных снимков и второй физический компьютер ещё нужны для окончательной сдачи. Шестистраничный PDF - исторический черновик протокола1.5 с исправленным именем; текущие измерения в models/expanded_parts_training.json и models/visual_parts_training.json. Помощь Codex раскрыта, студенческие вклады не выдумываются.

Проверки релиза: VALIDATION.md. Метод: INSTANCE_ANALYSIS.md. Источники/лицензии: THIRD_PARTY.md, models/expanded_dataset.json, data/regional и samples/sources.json. Старые MODEL_AND_COLOUR.md/PROTOTYPE_VALIDATION.md сохраняют историю прежних протоколов.
