# Tashkent CarVision 1.7

Владелец: София Рахматулаева. Локальный Windows10/11 x64 прототип: контуры автомобилей, автоматические марки, варианты моделей и восемь цветов. Без платных API, ключей и сети при распознавании.

Распакуйте **TashkentCarVision-v1.7-Portable.zip** целиком и запустите **CarVision/CarVision.exe**. Переносите всю папку; не запускайте EXE прямо из ZIP.

1. «Открыть фото» → «Анализировать фото» для всего кадра.
2. «Выбрать зону мышью» → обведите машину → «Распознать в зоне».
3. Нажмите контур или строку: справа три варианта модели и варианты цвета. Проценты не гарантируют правильность.
4. «Вся фотография» снимает зону; «Крупнее» показывает изолированную машину.
5. «Подробные настройки» раскрывают режим мелких машин и пояснённые пороги. Начните с0.5.
6. «Ответ для задания» копирует требуемые пары. «Копировать варианты» — подробности. Экспорт: TXT, details.txt, JSON, JPG.

Метод, обучение, измерения и ограничения: [INSTANCE_ANALYSIS.md](INSTANCE_ANALYSIS.md). Проверки: VALIDATION.md. Собственных учебных фото0; GitHub ожидается. Не все академические условия закрыты; отчёт docs/CarVision_Prototype_Report.pdf — шестистраничный черновик.

«Учебная разметка» сохраняет свои фото, марки/цвета, источник и группу машины/сессии. Для разработки из source скопируйте соседнюю папку models в source/models, создайте Python-окружение и установите requirements.txt; для инструментов подготовки/обучения также requirements-data.txt. Маски: prepare_instance_segmenter.py. Модели: train_vehicle_model_network.py → train_instance_vehicle_models.py → calibrate_instance_model_confidence.py. Цвет: train_masked_colour.py → calibrate_masked_colour_gate.py → train_paint_forest.py. Split/источники/метрики: models/*.json и data/*.jsonl. Скачанные публичные учебные фотографии в EXE не включены.

Предыдущие измерения1.3/1.4 сохранены в PROTOTYPE_VALIDATION.md и MODEL_AND_COLOUR.md как история. Актуальный метод — INSTANCE_ANALYSIS.md. Лицензии: THIRD_PARTY.md, licenses и samples/sources.json. CLI: CarVision.exe predict photo.jpg --mode fast --region 100 100 800 600 --single --output outputs.

## Обновление 1.6

Более спокойный интерфейс, белая карточка выбранной машины, образец цвета и три шкалы вариантов модели. Панель результатов прокручивается на небольшом экране. После загрузки другого фото прежние варианты очищаются. Подсветка повторяет сохранённую маску, включая отверстия, а не закрашенный многоугольник.

Исправлено распределение пикселей: мягкое предположение вне принятого контура соседней машины больше не отнимает пиксели у найденной машины. Повторное использование той же фотографии и настроек ускорено кэшем контуров по пикселям; другие фотографии и настройки пересчитываются. Кэш хранит только последний кадр.

Веса не переобучались в 1.6. Академические метрики и шестистраничный PDF относятся к обучению 1.5; это не новая оценка точности 1.6. Текущие инженерные проверки — VALIDATION.md. Остатки требований к собственным данным и GitHub сохраняются.

## Обновление 1.7: сравнение видимых деталей

Собственный модуль сравнивает изображение с 3740 представлениями из374 учебных фотографий: целые машины, верхние55%/35% и левые/правые65%. Представления извлечены нашей ранее обученной сетью; готовый классификатор моделей не скачивался. Поиск учитывает внешний вид и соотношение сторон; форма силуэта сама по себе не доказывает модель. Параметры сравнения и уверенности выбраны только по validation, без теста и шести городских примеров.

«Все изученные варианты» открывает полное ранжирование16 известных моделей. Это не все автомобили мира. На узкой крыше, маленькой или обрезанной машинe название не подтверждается, но предположения остаются доступны. Проценты показывают относительный выбор среди изученных классов, а не вероятность правильного ответа для любой машины.

На80 отложенных вырезках top-1 целой машины:73.8→78.8%; верхних55%:33.8→42.5%; верхних35%:16.3→22.5%. Top-3:96.2→93.8%,55.0→65.0%,36.2→46.3% соответственно. Полная вырезка немного потеряла в top-3; крыша всё ещё распознаётся ненадёжно. Искусственные верхние вырезки не заменяют реальный уличный тест. Подробности: models/visual_parts_training.json.

Во вкладке обучения теперь описаны четыре шага, текущий объём своего набора, назначение эпох, резервный поиск и отдельное обучение названий моделей. После нового обучения на своих марках/цветах используется обученная цветовая голова; COCO-контуры и16 названий моделей эта кнопка не переобучает.
